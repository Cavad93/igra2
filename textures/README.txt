Paper003 — CC0 parchment texture
=================================

Этот каталог содержит текстуры, используемые Pixi.js battle map.

Требуемый файл:
  Paper003_1K_Color.jpg  — 1024×1024 JPEG, CC0

Источник (CC0, ambientCG):
  https://ambientcg.com/get?file=Paper003_1K-JPG.zip

Установка:
  1) Скачать ZIP по ссылке выше.
  2) Распаковать и положить файл Paper003_1K_Color.jpg в этот каталог.

Fallback:
  Если файл отсутствует или сеть недоступна, ui/battle_map_pixi.js
  использует процедурный парчмент (buildProceduralParchmentCanvas),
  что позволяет карте рендериться без бинарных ассетов в git.
