# Baseline + финальный отчёт (Sessions 1 → 15)

Данные собраны скриптом [`perf/profile.mjs`](profile.mjs): headless Chromium
(Playwright) загружает `index.html`, мокает внешние AI-API, выполняет
`initGame()` + 10 последовательных `processTurn()`. Тайминг каждого шага
берётся из `console.time`/`console.timeEnd` в [`engine/turn.js`](../engine/turn.js)
(initScript перехватывает их и печатает в stdout префиксом `[perf-step]`).

## Цель vs реальность

**Цель плана:** p50 per-turn **< 1000 ms** (×3.2 от baseline).

**Результат:** p50 = **1618.7 ms**, ускорение **×1.96**. Цель не достигнута
по абсолюту (хоть и достигнута по ключевым ступеням — AI ×5.2, Армии ×4).
Причины недобора:
1. Экономика осталась доминирующей (41% per-turn) и даёт 742 ms. Session 3
   нашёл только 27 stub-наций из ожидаемых 600 — `regions_data.js` раздал
   слоты всем регионам. Чтобы добрать, нужен более агрессивный критерий
   («нация с <5k населения»), но это уже изменение поведения, не чистая
   оптимизация.
2. Session 13 мемоизация `_calcSlotBaseOutput` дала −8% на экономике, но
   полный мем-кэш `_computeRegionProduction` не был прописан — требовал
   бы инвалидации при миграции населения (fine-grained), что выходит
   за scope одной сессии.
3. p95 доминируется 10-м ходом (3186 ms vs p50 1618 ms): первый полный
   tier tier2 AI + первая рецессия в экономическом цикле. Если срезать
   warm-up — p95 упал бы до ~2000 ms.

## Регрессионный guard

Добавлен `tests/perf/turn_budget_test.cjs` — читает `perf/last_run.json`
и падает, если любая ключевая метрика вышла за бюджет
(Session 14 p50/p95 × 1.2). См. README в заголовке файла.

Запуск:
```bash
node tests/perf/turn_budget_test.cjs                # проверить существующий snapshot
RUN_PROFILE=1 node tests/perf/turn_budget_test.cjs  # снять свежий + проверить
```

Бюджет (ms):

| метрика        | p50  | p95  |
|----------------|-----:|-----:|
| total          | 2541 | 8014 |
| Экономика      | 1138 | 5541 |
| ИИ думает      |  216 |  314 |
| Население      |  200 |  300 |
| Заговоры       |  100 |  200 |
| Армии          |   50 |  100 |
| Сохранение     |   30 |   50 |
| Договоры       |   20 |   30 |
| Рендер         |   20 |   30 |
| boot           | 4000 |   —  |

Бюджет total p95 = 8014 ms специально «щедрый» — 10-й ход всегда тяжелее
из-за warm-up, и разброс p95 между прогонами 3200–6700 ms. Если p95
превысит 8000 ms — это реальная регрессия, не шум.
